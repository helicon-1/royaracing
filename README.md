# Roya Racing

Official website for **Roya Racing** — Saudi STEM Racing (F1 in Schools), Professional Class, Riyadh. Founded November 2025.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Zustand (client state)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
